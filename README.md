# Prediction Based Expense Tracking System

A full-stack web application built using the MERN stack that allows users to track daily expenses and predict future spending using Linear Regression.

## Features

- User authentication
- Add, edit, and delete expenses
- Monthly income (salary) tracking
- Expense categorization
- Expense visualization using charts
- Future expense prediction

## Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js

## Prediction Logic

The system uses Linear Regression to analyze historical expense data and estimate future expenses based on spending trends.
